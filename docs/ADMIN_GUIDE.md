# Как управлять классом

Это инструкция для человека. Код открывать не нужно.

В прототипе один класс: **8Б**, предмет **математика**. Заявки учеников принимает учитель-администратор. Технический администратор бота сам по себе класс не ведёт.

Команды ниже запускаются из корня репозитория, в том окружении, где лежит нужная `DATABASE_URL`. На боевую базу их не копируют вслепую: сначала просмотр, потом `--yes`.

## Кто есть кто

| Кто | Как узнать | Что может |
| --- | --- | --- |
| Учитель-администратор | в `users` колонка `manage` равна `да`, роль `teacher` | заявки, люди, предметы, передача управления |
| Обычный учитель | роль `teacher`, `manage` равно `нет` | свои класс и предмет. Заявки не принимает |
| Ученик | роль `student` | свой прогресс. Управления нет |
| Технический администратор | id MAX записан в `ADMIN_MAX_IDS` | консоль. Права класса эта переменная не выдаёт |

## 1. Назначить первого ответственного

Человек уже должен нажать «Согласен» в боте `ideya_fiks_101_bot`. Команда новых людей не создаёт и по имени не ищет.

Посмотреть всех:

```text
python -m app.admin users
```

Колонки: `id`, `role`, `status`, `manage`, `max`, `name`. Для назначения берётся колонка `max`. Это id человека в MAX, не внутренний `id` и не имя.

Просмотр без записи, подставьте свой `max`:

```text
python -m app.admin grant-school-manager MAX_ID
```

В ответе будет роль, статус и фраза «Изменений нет». Если id не цифровой или человека нет, команда остановится и базу не тронет.

Запись:

```text
python -m app.admin grant-school-manager MAX_ID --yes
```

После этого человек становится учителем класса 8Б по математике, `manage` становится `да`. Свободный первый вход закрывается: следующий случайный посетитель администратором не станет. Удаление этого человека место заново не открывает.

Проверка:

```text
python -m app.admin class
python -m app.admin users
```

В `class` строка «Ответственный» показывает имя. В `users` у этого `max` стоит `manage да`.

## 2. Посмотреть заявки

```text
python -m app.admin claims
```

Колонки: внутренний `id`, `max`, имя, класс, время. Если ответственного нет, последняя строка так и говорит.

В боте ответственный пишет `заявки`. Если заявок нет, бот отвечает «Заявок нет.» Если права нет, бот пишет, кто принимает, либо что ответственный не назначен.

В кабинете: «Войти в кабинет», затем «Управление классом», раздел «Заявки».

## 3. Принять ученика

Это делает учитель-администратор, не консоль.

В MAX: `заявки`, кнопка «Принять …». Ученику приходит: «Тебя приняли в класс 8Б».

В кабинете: «Управление классом», «Заявки», «Принять».

Повторное нажатие второе зачисление не создаёт. Бот отвечает, что заявки уже нет.

## 4. Отклонить ученика

Кнопка «Отклонить …» в том же списке или в кабинете. Ученику приходит, что заявку отклонили и можно написать учителю.

## 5. Добавить обычного учителя

В кабинете ответственного, раздел «Ученики» или «Учителя»: «Сделать учителем» у нужного человека. Это не выдаёт `manage`.

Затем раздел «Предметы»: выбрать учителя, класс 8Б, предмет «Математика», кнопка «Назначить».

Проверка: `python -m app.admin class` увеличивает «Учителей математики». В `users` у нового учителя `manage` остаётся `нет`.

## 6. Передать управление

Просмотр:

```text
python -m app.admin transfer-school-manager MAX_ОТ_КОГО MAX_КОМУ
```

Запись:

```text
python -m app.admin transfer-school-manager MAX_ОТ_КОГО MAX_КОМУ --yes
```

Оба id из колонки `max`. У первого `manage` должно быть `да`. После команды заявки принимает второй. Первый остаётся учителем, но без управления. Нельзя снять последнего ответственного, не назвав следующего.

## 7. Заблокировать

Внутренний `id` из первой колонки `users`, не `max`:

```text
python -m app.admin block ID
python -m app.admin unblock ID
```

В кабинете те же действия: «Заблокировать» и «Разблокировать». Себя команда кабинета заблокировать не даёт.

## 8. Кто сейчас управляет

```text
python -m app.admin class
python -m app.admin users
python -m app.admin audit
```

`audit` показывает `grant_school_manager` и `transfer_school_manager` без телефона и без текста вопросов. Если заявки копились без ответственного, там есть `claims_without_manager`.

## Команды бота

Их пишет учитель в чат с ботом:

| Фраза | Что будет |
| --- | --- |
| заявки | список и кнопки «Принять», «Отклонить» |
| ученики | имена и состояние: в классе или заявка ждёт |
| мой класс | 8Б, математика, ответственный, числа |
| войти в кабинет | кнопка входа |

Ученик этих списков не видит.
