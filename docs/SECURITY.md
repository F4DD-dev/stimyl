# Чек-лист безопасности

Состояние на 2026-10-30. Пункт закрыт только там, где это есть в коде или в настройке, которую можно проверить.

| Проверка | Сейчас |
| --- | --- |
| Секреты только в окружении, не в git | `.env` в `.gitignore`, в репозитории `.env.example` |
| `SESSION_SECRET` не `change-me` | Код предупреждает в логе. На боевом окружении это обязанность переменной |
| Пароль базы не в логах | В лог пишется тип ошибки, не текст исключения и не URL |
| Пользователь базы не суперпользователь | В коде не проверяется. Задаётся в панели Timeweb, см. `docs/DEPLOY.md` |
| TLS базы | `ssl=require` шифрует без проверки сертификата. Для проверки нужен `sslmode=verify-full` и известный CA |
| Вебхук | `X-Max-Bot-Api-Secret` сравнивается через `hmac.compare_digest` |
| initData | HMAC-SHA256 с ключом `WebAppData`, `auth_date` не старше часа. Роль из клиента не принимается |
| Cookie кабинета | `httpOnly`, `SameSite=lax`, `Secure` при `COOKIE_SECURE=true`. В cookie нет роли, только случайный токен, в базе его хэш |
| Код входа | 6 цифр, 5 минут, один раз, 5 неудачных попыток с одного IP, 5 кодов в час |
| CORS | Пустой `CORS_ORIGINS` — заголовки CORS не выдаются. Если задан, только перечисленные origin |
| Заголовки | `nosniff`, `Referrer-Policy: no-referrer`, CSP на свои скрипты и `https://st.max.ru`. `frame-ancestors` нет: неясно, с какого origin MAX открывает мини-приложение |
| Лимиты входа | Есть на код кабинета. Общий лимит на все API ещё нет |
| Зависимости | Версии в `pyproject.toml` нижними границами, без хэшей. CI запускает `pip-audit` с `continue-on-error` |
| Логи | JSON, `request_id`. Текст вопроса, токен и initData туда не пишутся |
| Изоляция | Учитель читает только свои классы. Чужой `class_id` даёт 403. Ученик не открывает `/api/teacher/class`. Тесты в `tests/test_accounts.py` |
| Удаление | `close` прячет аккаунт, `delete --yes` стирает занятия и вход. Журнал хранит действие без имени |
| Фото | Учителю не отдаётся. Файл по-прежнему не скачивается с MAX: это следующий этап |

Мини-приложение не ходит в PostgreSQL. Все запросы идут в FastAPI.
