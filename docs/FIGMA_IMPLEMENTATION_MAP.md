# Карта переноса Figma Make

Источник: https://kilt-filter-87336403.figma.site/  
Сборка: `assets/index-Wz4IrrT1.js`, `assets/index-Dt3Lw7am.css`.  
Просмотрены живые переходы на ширине телефона (колонка приложения около 390–430 px).

Тёмная полоса «101_Идея_фикс» с кнопками «Закрыть», «Ещё» и «Развернуть» — хром мессенджера внутри макета. В мини-приложение не переносится.

Демо-имена и цифры макета (Анна, Миша, 4 ученика, МИ/АК/НС) в API и базу не пишутся. Композиция сохраняется, числа берутся из ответа сервера.

## Экраны

| Экран Figma | Роль | Раздел приложения | Реализуемый API |
|---|---|---|---|
| Обзор класса | Учитель | `#/overview` | `GET /api/teacher/class`, `GET /api/teacher/assignments`, `GET /api/notices` |
| Карта класса | Учитель | `#/class` | `GET /api/teacher/class` |
| Помощник учителя | Учитель | `#/stimul` | Отдельного API модели нет. Отправка не имитирует ответ. |
| Задания, пустой список | Учитель | `#/tasks` | `GET /api/teacher/assignments` |
| Создание работы | Учитель | `#/compose` | `POST /api/teacher/drafts`, `POST /api/teacher/assignments`, `POST /api/teacher/works/{id}/publish` |
| Результат работы | Учитель | внутри `#/tasks` | `GET /api/teacher/works/{id}` |
| Профиль учителя | Учитель | `#/profile` | сессия и `GET /api/teacher/class` |
| Профиль ученика | Ученик | `#/profile` | `GET /api/student/progress`, `GET /api/student/works` |
| Уведомления | Обе роли | нижняя панель | `GET /api/notices`, `POST /api/notices/{id}/read` |
| Управление классом | Учитель с `can_manage_school` | `#/manage` | `/api/manage/*`. В Figma отдельного экрана нет, остаётся существующий сценарий. |

Отдельных экранов ученика «Обзор», «Класс», «Задания» и «Стимул» в прототипе нет. Переключатель «Учитель / Ученик» на профиле только подменяет демонстрационную карточку Миши и не является сменой роли. В продукте ученик остаётся на своих маршрутах и не открывает карту класса.

## Учитель

### Обзор класса

- Подпись «Обзор класса», приветствие с именем из профиля, текст про старт класса, если проверок ещё не было.
- Фиолетовый блок: «Можно начинать», знак, «Первая работа», кнопка «Создать работу». Кнопка открывает мастер проверки (`#/compose`), а не пустой список, как общий `onClick` в прототипе.
- Две карточки: ученики и проверки. Ноль учеников — число 0 без выдуманных аватаров. Ноль проверок — тёмная карточка «пока не проводились», без графика результатов.
- «Фокус недели»: темы из программы класса. «Вся карта» открывает `#/class`. В прототипе эта кнопка ошибочно вызывает тот же переход, что и «Создать работу».

### Карта класса

- Заголовок «Карта класса», фильтры «Все темы / Усвоено / Практика / Повторить».
- Сводка «Пока нет данных», пока нет проверенных попыток.
- Строка темы ведёт к фокусу темы и сборке задания. Отдельного экрана темы в прототипе нет: кнопка «Открыть тему» без перехода.

### Стимул

- «Помощник учителя», три подсказки, поле и кнопка отправки.
- В макете после отправки написано «Запрос отправлен помощнику». Модель не подключена, поэтому продукт показывает, что сообщение не ушло. Фото в композиторе выключено.

### Задания

- Пустое состояние: иллюстрация листов, «Работ ещё не было», «Создать первую работу», жёлтая подсказка про 5–7 вопросов.
- Если работы есть, список приходит из API. Плюс открывает мастер.

### Профиль

- Карточка с буквой имени, роль «Учитель», подпись куратора класса.
- Строки: класс, предмет, кто проверяет заявки. При `can_manage_school` строка заявок открывает `#/manage`.
- «Изменить» не сохраняет профиль: имени в API правки нет, показывается пояснение, что имя приходит из MAX.
- «Настроить» открывает уведомления. Текст про личные вопросы сохранён.

## Ученик

Прототип показывает только профиль: тёмно-синяя карточка, «Работы» и «Темы», блок «Мой прогресс», подсказка про личный диалог.

- «Открыть карту знаний» ведёт на личную карту `#/map`.
- Число тем и работ берётся из прогресса и списка работ, не из четвёрки макета.
- Обзор, темы, задания, занятие и личный «Стимул» остаются прежними сценариями и получают общую шапку, бумагу и нижнюю навигацию. Их композиции в Figma нет.
- Ученик не видит фильтр класса, чужие результаты и управление школой.

## Навигация

Пять вкладок: Обзор, Класс, Стимул, Задания, Профиль. У ученика вторая вкладка называется «Темы» и открывает только свой прогресс.

Активная вкладка: фиолетовая чёрточка сверху и мягкий фон у значка. Центральная вкладка — знак из трёх точек.

## Что в прототипе не делает переход

- Колокольчик и аватар в шапке макета без действия. В продукте колокольчик открывает уведомления, аватар — профиль.
- Фильтры карты в исходнике только подсвечивают чип и не скрывают темы. В продукте фильтр оставляет темы с выбранным статусом.
- Кнопки «Класс» и «Предмет» в профиле макета без действия. В продукте открывают выбор класса, если классов больше одного.
